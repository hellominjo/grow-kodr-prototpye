# GROW · K-ODR / SWPBS 프로토타입

React + Vite + Tailwind CSS 4 + MUI + Pretendard. Node.js 20.19+ 권장.

```sh
npm install
npm run dev
```

표시되는 localhost 주소로 접속합니다. `npm run build`로 dist를 생성하며 `npm test`로 분석 로직을 검증합니다.

## 사용 순서
1. 초기 날짜 2026-10-01 ~ 2026-10-14에서 ODR 28건과 긍정적 관찰 22건을 확인합니다.
2. 매트릭스 셀을 클릭해 주간 추이와 관련 기록을 확인합니다.
3. ODR 간편 기록에서 장소·가치·행동 등을 저장합니다. 기록을 클릭하면 수정할 수 있습니다.
4. 행동 기록 화면 또는 셀 상세에서 긍정적 관찰을 별도로 추가합니다.
5. 매트릭스에서 낮음(0–1건), 주의(2–4건), 경고(5건 이상)를 필터링합니다. 선택 기간의 셀별 빈도 기준이며 학생 위험도가 아닙니다.
6. 새봄이 패턴에서 교사가 지정한 Tier 2 데모 상태와 장소·시간대·기대행동별 일일 그래프, 기간 전반·후반 변화와 이전 기간 비교를 확인합니다.
7. 지도 및 추적, CICO, 리더십팀 메뉴는 현재 버전에서 제외했습니다.

## 계산과 한계
- 모든 분석은 현재 저장된 기록과 날짜 필터에 기반합니다. 브라우저 localStorage에 자동 저장됩니다.
- 이전 기간은 선택 기간 바로 전의 같은 일수입니다. 시작일 기준 7일 구간을 만들며 마지막 구간은 짧을 수 있습니다.
- 셀 연결은 장소 + 교사가 선택한 기대행동 가치입니다. 행동 문장에서 자동으로 기능이나 가치를 추론하지 않습니다.
- 반복 패턴: 장소 × 기대행동 가치 × 시간대가 2일 이상, 3건 이상 기록된 경우입니다.
- 변화점은 마지막 두 주간 구간의 건수 차이를 보여 주는 탐색 후보이며 통계적 변화점 탐지가 아닙니다.
- 긍정적 관찰은 독립적인 기록입니다. ODR 감소를 기대행동 증가로 해석하지 않습니다. 출석·관찰 기회·학급 규모로 보정한 발생률은 아닙니다.
- AI는 외부 모델을 호출하지 않는 모의 규칙 기반 문구입니다. 행동 기능을 확정하거나 학생 위험점수를 생성하지 않습니다.
- 가상 데이터 전용 데모입니다. 서버·인증·교사 간 공유·보안 권한 기능은 포함되지 않습니다. 실제 학생 개인정보를 입력하지 마세요.
- 초기화하려면 브라우저 사이트 저장소의 odr-v1, positive-v1, plans-v1, cico-v1 키를 삭제합니다.
- Pretendard는 CDN에서 불러오며 접속이 안 되면 시스템 글꼴로 표시됩니다.

## 최신 업데이트
- 새싹·AI 반짝임과 다색 GROW 워드마크를 SVG 로고로 적용했습니다.
- ODR 기록 버튼은 모든 화면의 상단 고정 영역에 있습니다.
- AI 행동전문가: 학급 전체 패턴 그래프, 기간 비교, 반복 근거와 Tier 1 제안, 해석 한계 및 인쇄/PDF 저장.
- Tier 2 학생지원: 여러 학생의 가명을 추가하고 선택해 개별 패턴을 확인합니다. 명단은 grow-tier2 키에 저장됩니다.
